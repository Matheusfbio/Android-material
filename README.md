# Android Material Components (XML)

https://github.com/user-attachments/assets/98cb5e8d-229d-4002-8c24-511bc3d1a021


Este projeto é um guia prático e demonstrativo dos principais componentes do Material Design para Android, utilizando a abordagem tradicional de construção de UI com XML.

O objetivo é servir como um material de consulta rápida e um exemplo de implementação para desenvolvedores que trabalham com o sistema de Views do Android.

## 📱 Componentes Demonstrados

O aplicativo é dividido em várias seções, cada uma focada em um componente específico do Material Design. Com base nas atividades do projeto, os seguintes componentes são cobertos:

*   **Buttons:** Exemplos de diferentes tipos de botões, como `MaterialButton` (contido, tonal, de texto, outline).
*   **Text Fields:** Demonstração de `TextInputLayout` para caixas de texto modernas com labels flutuantes, ícones e mensagens de erro.
*   **Top App Bar:** Implementação da barra de aplicativos superior, incluindo menus e ações.
*   **Bottom Navigation:** Exemplo de uma barra de navegação inferior para alternar entre diferentes seções do app.
*   **Bottom App Bar:** Uso da barra de aplicativos inferior, frequentemente usada com um `FloatingActionButton` (FAB).
*   **Snackbar:** Como exibir mensagens rápidas e acionáveis na parte inferior da tela.

## 🚀 Como Executar o Projeto

1.  Clone este repositório.
2.  Abra o projeto no Android Studio.
3.  Aguarde a sincronização do Gradle ser concluída.
4.  Execute o aplicativo em um emulador ou dispositivo físico.

A tela principal do aplicativo contém um menu que permite navegar para a demonstração de cada um dos componentes listados acima.

## 🛠️ Tecnologias Utilizadas

*   **Kotlin:** Linguagem de programação principal.
*   **XML:** Para a construção das interfaces de usuário (UI).
*   **Material Design Components:** Biblioteca do Google para implementar o Material Design no Android.
*   **View Binding:** Para acessar as Views de forma segura e concisa.
